# NeOn

Неоновый сайт: регистрация, вход, рассказы о себе и отзывы. Админ может удалять записи.
Сервер на Python (только стандартная библиотека) + база SQLite.

## Запуск
```
python3 server.py
```
Открой http://localhost:8000

## Стать админом
Зарегистрируйся на сайте, затем:
```
python3 server.py --admin ТвоеИмя
```

## Важно
GitHub хранит код, но не запускает Python-сервер. Чтобы сайт работал в интернете, нужен свой компьютер
с туннелем (cloudflared) или VPS. Файл `neon.db` (аккаунты) в репозиторий не попадает.
